## 三条独立人生改造

- Node 剧情测试 7 项通过：穷举 2,187 种组合，医学、草原创业、星际各 729 种；每局都经过所选路线的八个专属节点，再抵达相遇、订婚及哈尔滨生日。创业和星际剧情没有被切回学医、备考或读博。
- 选择后果检查通过：童年所得改变成年突破，事业／发明改变下一幕与大事件，应对方式改变转折，双人活动改变水果蛋糕的缘由，未来计划改变生日出发前的安排。星际相遇只使用先前造过的专属装备，另两种方式使用公共救援工具。
- 当前代码的 Chrome / WebKit / 手机触摸共 11 项浏览器检查通过。三条完整路线检查实际到访节点、路线标识、相应角色造型和结尾身份，保留完成／跳过互动、动态行走、重新开始、键盘与音乐检查。
- Codex 内置浏览器实走「第一桶草 → 星际人生 → 复习枕头」：看到第一桶草长成失重发光草坪、承包远航经费，随后好梦号进入整船催眠事件。查看了创业总部和星际危机的实际画面，背景、人物、选项和对话没有溢出。
- 三条代表路线各 26 个剧情／选择结果画面；正文与标题约 1,833—1,922 字，不含结尾信和选项。5—7 分钟仍是设计目标，需要自然阅读试玩确认。

## 保留的动态角色与背景


- 浏览器测试共 11 项通过：Google Chrome 1440×900 与 Playwright WebKit 1280×720 各 3 条完整路线、各 1 项键盘/音乐/口袋测试、各 1 项开启动画的角色交互测试，加 1 项 Pixel 7 尺寸的手机触摸冒烟测试。
- 完整路线覆盖实际点击全部小游戏与全部跳过、纪念物回收、生日信与重新开始。结尾有 11 件纪念物；重开后恢复为 0。
- 桌面测试检查背景铺满视口、对话框和选项无溢出、角色图片已加载、对应背景已绘制；未观察到 JS 异常或资源 HTTP 错误。
- 键盘测试覆盖 Enter 开始、数字选项、空格继续、B 打开口袋与 Esc 关闭；打开口袋时数字键不推进剧情。
- 实际查看桌面首页、第一章、相遇、生日点烛和结尾画面。移除了结尾遮挡文字的重复蛋糕；桌面点烛直接对应背景生日桌，窄屏使用独立可点击蛋糕。
- 秋月沿用童年、校服、实验服、医学生、初见、日常、成都水果事业、生日八种形态，按路线与场景选用；首页仅秋月，尹航白衬衫从相遇结果后的共同场景加入。
- 9 种形态各有 6 帧待机、8 帧行走和 4 帧招呼／伸手，共 162 帧。每种打包为 1536×624 透明精灵图；实际 Canvas 帧变化、点击空地移动、角色问候、到达后拾取、跳过时取消待处理动作均通过浏览器检查。
- 162 帧联系表复查未见空白、裁头裁脚或明显尺寸跳变。已知两处轻微装饰变化：成都行走帧的柠檬贴位置略漂移，生日发夹在行走与待机之间换侧，不影响角色识别和动作。另在 Codex 内置浏览器实际点地面行走、点角色问候，观察到童年形态和「这个院子我罩了！」对白。
- 首轮逐张加载动作帧时本地 Python 服务出现连接中断，已改为每种形态一次加载精灵图；修复后 11 项全通过。随后将招呼末帧保持到动作结束，避免重复起手，两个浏览器的动作交互测试再次通过。
- 9 组背景各有两张 1672×941 源图，逐张检查，无人物或烘焙进图中的 UI。局部柔边遮罩让叶片、水面、灯光约每 5.2 秒循环变化，建筑和主体构图保持基础图；浏览器实际像素采样确认背景在变化。
- 通过 `output/site/` 子路径运行，资源均用相对路径加载。发布包约 17 MB，包含 18 张 WebP 背景与角色精灵图、对话头像；原始照片、原始背景 PNG 和角色过程稿不进入发布包。
