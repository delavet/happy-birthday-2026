# 秋月的地球online漫游 · 制作稿

## 已确认

- 送给张秋月的 31 岁生日礼物，男主角称呼尹航。
- 生日：2026 年 9 月 25 日，农历八月十五。电脑优先，目标单次 5—7 分钟；手机保留触摸操作。
- 喜剧为主，允许大幅架空和无厘头；医学、草原创业、星际三条人生从童年后真正分开，选择后持续沿各自路线生活。相遇、相爱与哈尔滨共同庆生是固定结局。
- 秋月从成都出发，尹航从北京出发，先在哈尔滨过生日，之后计划去牡丹江。
- 原始照片只在仓库外保存。公开版本是否展示真实合照，等待用户选择。
- 视觉调整：背景铺满屏幕，文本通过对话框和 UI 浮在场景上；先根据照片单独创作角色，再放入场景。
- 首页以秋月独自登场，尹航从相遇后的共同场景才加入。角色采用类似桌面宠物的 Q 版比例；尹航穿秋月喜欢的白衬衫，秋月以圆眼镜、笑容和洞洞鞋保持辨识度，现有八种形态按路线及阶段选用，招呼对白也与路线对应。

## 故事与互动

年龄仅作游戏章节划分，求学、相识等真实事件的具体岁数尚未确认，不把推定年份写成传记事实。

| 章节 | 医学人生 | 草原创业人生 | 星际人生 |
| --- | --- | --- | --- |
| 01 草原出生点 · 1—6 | 共同起点：通辽大院、动物、杏树；选择动物会长徽章、杏树的勇气或第一桶草，捡三颗杏子 | 同左 | 同左 |
| 02 世界的岔路口 · 12—17 | 背上书包，到通辽寄宿，保留朋友、成绩与英语偏科的真实素材 | 经营摸狗体验店，成立动物联邦，不必等毕业再行动 | 在杏树上练习摇花手，飞离地表，不进入求学线 |
| 03 点子成真了 · 20—22 | 兰州大学、奖学金、大二科研；选择五鼠迷宫、催眠枕或动物翻译机 | 选择草原乐园、水果公司或动物快递，把童年所得变成真实经营优势 | 选择花手巡航、杏树太空电梯或好梦导航，让童年所得参与远航 |
| 04 人生大事件 · 25—26 | 北京艰苦求学，选择快乐科、音乐整理或花束审稿，改变旧课题和生活方式后毕业 | 柠檬树董事会因老板试吃太多撤掉试吃岗位，选择正式试吃岗、音乐传送带或休假制度，改变经营方法 | 旧发明惹出航行事故，选择音乐整理、动物轮班或免打扰假期，继续生活在宇宙里 |
| 05 命运的小插曲 · 27—28 | 毕设后回家无票，朋友介绍尹航；三种赴约方式 | 先前的经营办法引来新客人；面试试吃员、一起配送或柠檬树主持聊天 | 在失重区遇到穿白衬衫的尹航，使用此前发明救援、洞洞鞋安全绳或借用小推车接人 |
| 06 两个人的日常 · 29—30 | 共同回忆：花、生日弹弓、日常三选一、水果蛋糕、阿那亚拾贝、六月订婚 | 保留共同回忆，生日会、日常与订婚对应动物联邦生活 | 保留共同回忆，生日会、日常与订婚对应太空生活 |
| 07 下一件大事 · 31 | 成都读博与水果商机；小摊、旧课题再就业或柠檬董事长 | 成都新分店；返乡合伙、移动快乐分店或让公司自己运转 | 太空果园；月球外卖、小行星花园或动物星际春游；飞船暂泊成都 |
| 08 今晚的月亮 · 31 | 共同抵达：秋月从成都、尹航从北京赴哈尔滨；农历八月十五许愿与生日信 | 同左，创业家身份和沿途选择保留到结尾 | 同左，宇航员身份和沿途选择保留到结尾 |

这里的 27—28、29—30 是故事进度标签，不给相识或订婚附加未经确认的具体年龄。正式页面以人生阶段为主、旅程年龄进度为辅。

三条路线各有 `teen`、`work`、`breakthrough`、`crisis`、`turning`、`meeting`、`future`、`packing` 八个专属节点，共 24 个。相遇后的共同节点会按路线改变场景与对白；六月订婚后再进入各自的未来与出发节点。非医学线不会被强制安排入学、备考、学医或读博。生日信中的真实经历另以“现实里的你”说明。

每局保留七次三选一，共 2,187 种组合，其中每条人生路线各 729 种。早先的选择会在后面产生具体事情：

| 选择 | 状态 | 后续影响 |
| --- | --- | --- |
| 童年身份或所得 | `origin` | 改变各线起步及突破节点，例如第一桶草变成科研经费、草原启动资金或飞行资源 |
| 人生岔路 | `career` | 选择完整路线，持续影响专属节点、共同日常、人物装扮与对白、结尾身份 |
| 事业或发明 | `project` | 改变突破、后续大事件以及未来事业，旧发明和旧生意继续出现 |
| 应对大事件 | `approach` | 改变下一幕的解决办法与生活方式，创业线还改变尹航来访的缘由 |
| 相遇方式 | 选择记录中的第 4 章 | 三种办法都会相遇，各自留下不同纪念物，并在生日信中回响 |
| 两个人的活动 | `partnerActivity` | 做饭清单、双人设计图或双排约定，分别改变下一幕水果蛋糕的制作缘由 |
| 未来计划 | `ambition` | 在出发前兑现新事业、新安排或新目的地，然后休假赴哈尔滨 |

医学线中的寄宿、兰州科研、北京求学、成都读博来自真实经历，五鼠开会等属于夸张改编。创业与星际线允许完整架空；两个人的真实回忆经过相应场景改编后保留。

## 实现范围

- 原生 HTML / CSS / JavaScript，无后端；站内资源使用相对路径，适配 GitHub Pages 仓库子路径。
- 场景、选择、结果分屏；选项改变后续节点、场景及纪念物，画面上显示当前路线标识。`src/story.js` 管理共同故事和状态，`src/routes/medicine.js`、`src/routes/business.js`、`src/routes/space.js` 分别管理三条路线。
- 9 组像素背景，每组两张；只在树叶、水面和光点区域循环混合。电脑画面底部对话框、右侧选项、顶部旅程信息。
- 沿用秋月八种形态与尹航白衬衫形态，每种各 18 帧待机、行走、招呼动作，合计 162 帧；按路线与阶段选用，创业使用围裙和日常装，星际使用训练服、背带裤及检修外套。点空地可走动，点角色会打招呼；点物件后先走近、伸手，再领取。
- 四个轻互动无倒计时、无失败惩罚，均可跳过；只需点击，不依赖拖动精度。
- 可静音的原创 Web Audio 短旋律，用户手动开启；支持减少动态效果设置。
- 保留故事与画面源文件，便于当天快速调整。生日信是代拟文案，供尹航试玩后修改。

## 验收

- 电脑浏览器实际从首页玩到生日信；测试不同选择和跳过小游戏都能抵达。手机另做触摸冒烟检查。
- 穷举 2,187 种组合，检查每条路线各 729 种，经过自己的八个专属节点，并最终完成相遇、订婚和哈尔滨生日；创业与星际路线不会转回求学。
- 检查童年、项目、处理方式、双人活动与未来计划确实改变后续文本或场景，身份和相遇纪念物保留到结尾；不是仅更换按钮文字。
- 1440×900 与 1280×720 背景铺满、UI 不溢出；按钮可点击，键盘可推进，音效可切换，重新开始能清空上一局。
- 检查角色帧确实变化、走到目标后计数、跳过后取消旧场景拾取，以及背景局部帧变化。
- GitHub Pages 部署后另做真实网址通关；本地通过不称为已经上线。
