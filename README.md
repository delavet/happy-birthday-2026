# 秋月的地球online漫游

送给张秋月的 31 岁生日礼物。电脑优先的像素风人生奇遇小游戏，目标体验约 5—7 分钟。由真实回忆出发，允许脑洞把人生带去不同方向，最后秋月和尹航在哈尔滨一起过生日。

**在线游玩：[秋月的地球online漫游](https://delavet.github.io/happy-birthday-2026/)**。无需安装，无需保持本地服务运行，推荐使用电脑浏览器。

## 本地试玩

```sh
npm install
npm start
```

打开 `http://localhost:4173`。手机和电脑在同一局域网时，可用电脑的局域网 IP 替换 `localhost`。这是本地开发服务器，需保持电脑和服务运行。

推荐用电脑浏览器游玩。点击场景空地，秋月会走过去；点击角色，角色会挥手打招呼。点击小游戏物件，秋月会先走到物件旁，再伸手领取或互动，完成后才计入进度。鼠标点击选项；Enter / 空格开始或继续，数字 1 / 2 / 3 选择，B 打开回忆口袋，Esc 关闭口袋。手机保留触摸操作。

## 内容

- 8 章旅程，童年之后在世界的岔路口选择医学人生、草原创业人生或星际人生。三条路线各有 8 个专属节点，共 24 个；只有医学线继续寄宿、兰州科研、北京求学和成都读博。
- 每局 7 次三选一，合计 2,187 种选择组合，每条路线各 729 种。童年所得、事业或发明、应对事件的办法、双人活动和未来计划都会改变后续剧情；选择的路线保持到生日结尾。
- 医学线带着五鼠、催眠枕或动物翻译机完成科研；创业线经营草原乐园、水果公司或动物快递；星际线用花手飞船、杏树电梯或好梦导航继续远航。创业和星际线中途不会被强制送回校园或转成医生。
- 相遇的理由随路线改变：回家无票后的朋友介绍、动物联邦的新客人、失重区救援。之后保留生日弹弓、水果蛋糕、阿那亚和六月订婚等共同回忆，日常场景与对白继续对应各自的人生，最后在哈尔滨的农历八月十五一起庆生。
- 摘杏子、弹弓点气球、阿那亚拾贝与生日点烛。没有倒计时或失败惩罚，每个互动均可跳过。
- 回忆口袋、原创短旋律、静音、减少动态效果与重新开始。
- 结尾生日信由助手代拟，发布前可继续调整成尹航自己的口吻。
- 9 组独立像素背景铺满屏幕，每组由基础画面和动态画面组成，借助局部柔边遮罩循环混合树叶、水面与灯光；对话、选项和旅程信息浮在画面上。网页使用 18 张 WebP 背景资源。
- 首页只有秋月独自出场；沿用童年、校服、白大褂、洗手服、初见连衣裙、旅行背带裤、水果摊围裙和生日裙装八种动画形态，按路线和阶段选用服饰、场景与招呼对白。画面上的路线标识展示当前人生。尹航穿白衬衫与深色长裤，在相遇之后的双人章节加入。
- 秋月 8 种形态加尹航 1 种形态，每种包含待机 6 帧、行走 8 帧、招呼／伸手 4 帧，共 162 帧。每种形态的动作合在一张精灵图中加载，独立透明帧保留为制作素材。

## 编辑入口

| 文件 | 内容 |
| --- | --- |
| `src/story.js` | 共同章节、人生岔路口、路线信息、状态与选择结算、纪念物 |
| `src/routes/medicine.js` | 医学人生的 8 个专属节点，科研、求学与后续选择的影响 |
| `src/routes/business.js` | 草原创业人生的 8 个专属节点，动物联邦的经营、相遇与未来 |
| `src/routes/space.js` | 星际人生的 8 个专属节点，飞行发明、宇宙生活与失重相遇 |
| `src/main.js` | 游戏流程、轻互动、生日信 |
| `src/actors.js` | 八阶段角色映射、逐帧动画、点击行走、招呼与靠近物件后的领取流程 |
| `src/scenes.js` | 成对 WebP 背景加载、局部柔边遮罩循环与动态点缀 |
| `src/style.css` | 电脑优先的全屏场景、角色与浮动对话框 |
| `src/sound.js` | 原创 Web Audio 短旋律 |
| `assets/actors/` | 9 种形态各含 `spritesheet.png`（生产动画）和 `idle/00.png`（对话头像）；其余独立帧为制作素材 |
| `assets/qiuyue-sprite.png`、`assets/yinhang-sprite.png` | 最初的 Q 版设计参考，未用于生产角色动画，也不进入发布包 |
| `assets/scenes/` | 大院、校园、实验室、家、公园、海边、太空、水果摊、哈尔滨，各有基础与动态画面；发布时只取 WebP |
| `docs/story-plan.md` | 已确认事实、改编范围、待确认事项 |
| `docs/character-design.md`、`docs/scene-art-prompts.md` | 角色设计、原始形象与场景生成提示词 |
| `docs/animation-prompts/` | 9 种角色形态的 27 组动作条带生成提示词 |

原始照片保留在用户提供的仓库外目录，未复制进项目。游戏中的年龄是改编故事的进度，不将未经确认的求学、相遇年龄作为传记事实。游戏不发送玩家选择，不依赖外部图片或字体服务；刷新页面会重新开始。

## 验证

```sh
npm test
npm run build
npx playwright install webkit
npm run test:e2e
```

剧情测试穷举全部选择，检查 2,187 种组合按每条路线 729 种分布，每条路线经过自己的 8 个专属节点以及相遇、订婚、哈尔滨和生日。测试还检查路线不被切换、创业与星际线不被拉回求学，以及童年、项目、处理方式、未来计划和双人活动对后续节点的影响。

浏览器测试使用本机 Google Chrome（1440×900）和 Playwright WebKit（1280×720），从首页点击至生日信，覆盖三种路线、路线标识与专属节点、完成与跳过互动、纪念物回收、重新开始、音乐和回忆口袋。检查背景铺满、对话框与选项位于视口内、人物资源加载、键盘操作，并保留一项手机触摸冒烟测试。测试使用 `/output/site/` 子路径，验证 GitHub Pages 所需的相对资源路径。截图时启用减少动态效果。

上线后的同一套浏览器检查直接访问公开网址，不启动本地服务器：

```sh
PLAYWRIGHT_BASE_URL=https://delavet.github.io/happy-birthday-2026/ npm run test:e2e
```

浏览器模拟手机尺寸不替代实体手机试玩。验证记录见 [docs/verification.md](docs/verification.md)。

## GitHub Pages

`npm run build` 生成 `output/site/`，只包含 HTML、游戏源文件和网页资源。每种角色形态只发布 `spritesheet.png` 和对话头像 `idle/00.png`，背景只发布 WebP；其余独立角色帧、设计参考 PNG、背景 PNG 和生成过程文件不进入发布包。配置位于 `.github/workflows/pages.yml`，与仓库当前默认分支 `master` 对齐。

仓库 Pages 已配置为 GitHub Actions 发布，并开启 HTTPS。更新进入 `master` 后，工作流运行剧情检查、打包静态站点并部署。配置采用 [GitHub 官方 Pages 工作流](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages) 的 artifact 发布方式。

正式地址：[https://delavet.github.io/happy-birthday-2026/](https://delavet.github.io/happy-birthday-2026/)。部署状态见 [GitHub Actions](https://github.com/delavet/happy-birthday-2026/actions/workflows/pages.yml)。
